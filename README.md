## מה נאסף
הנתונים מגיעים מה-API הציבורי של מערכת הכרטוס של לב (`ticket.lev.co.il/api/presentations?locationId=1158`).
ה-API מציג רק הקרנות עתידיות (2-3 ימים קדימה), ומוריד כל הקרנה ברגע שהיא מתחילה. לכן אוספים כ-5 דקות לפני כל הקרנה: ה-workflow מתעורר כל 5 דקות, ו-`gate.py` מחליט אם לאסוף (הקרנה שמתחילה בתוך 8 דקות, או חצי שעה מאז הריצה האחרונה). ריצה שלא אוספת נגמרת בכמה שניות ולא מבצעת commit.

| קובץ | תוכן |
|---|---|
| `data/presentations.csv` | שורה לכל הקרנה: כל השדות שה-API מחזיר (סרט, אולם, שפה, משך, תחילת מכירה ועוד), ובנוסף מתי נראתה לראשונה ולאחרונה ומה הייתה הזמינות אז |
| `data/changes/YYYY-MM.csv` | שורה רק כשזמינות הכרטיסים משתנה: עקומת המכירות של כל הקרנה |
| `data/runs/YYYY-MM.csv` | שורה לכל ריצה: מאפשר לבדוק כיסוי ופערים |
| `data/attendance.csv` | אומדן כרטיסים לכל הקרנה שהתחילה |
| `data/summary.json` | סיכומים: לפי יום, חלון שעה, שבוע וסרט, והקרנות קרובות |
| `data/snapshots-flat.csv` | אותם נתונים בפורמט הישן של הכלים המקומיים |
| `data/legacy/` | צילומים שנאספו במחשב לפני שהמעקב עבר ל-GitHub |

## שיטת האומדן
כרטיסים = `round((1 - availRatio) × 267) − 2`. אולם לב סמדר מונה 267 מושבים (אומת מול מפת המושבים),
ו-2 מושבים חסומים גם כשאין מכירות. האומדן "סופי" כשההקרנה נראתה לאחרונה עד 20 דקות לפני תחילתה.
מכירות בקופה ברגע האחרון עלולות לא להיכלל.
