# מעקב קהל: לב סמדר

**לוח חי:** https://guy-go-ld.github.io/lev-smadar-tracker/ (מתעדכן לבד אחרי כל צילום)

איסוף אוטומטי של נתוני המכירות של קולנוע לב סמדר (ירושלים), עבור יוזמת סמדר.
GitHub Actions אוסף כל חצי שעה, ובנוסף 5 דקות לפני תחילת כל הקרנה, בלי תלות במחשב כלשהו.
האיסוף רץ ב-workflow בשם `loop`: ג'וב שבודק כל דקה במשך כ-5.5 שעות ואז מפעיל את הריצה הבאה של עצמו (התזמון של GitHub לא היה אמין). להפעלה מחדש אם השרשרת נעצרה: `gh workflow run loop.yml -R guy-go-ld/lev-smadar-tracker`.

## מה נאסף
הנתונים מגיעים מה-API הציבורי של מערכת הכרטוס של לב (`ticket.lev.co.il/api/presentations?locationId=1158`).
ה-API מציג רק הקרנות עתידיות (2-3 ימים קדימה), ומוריד כל הקרנה ברגע שהיא מתחילה. לכן אוספים כ-5 דקות לפני כל הקרנה: ה-workflow מתעורר כל 5 דקות, ו-`gate.py` מחליט אם לאסוף (הקרנה שמתחילה בתוך 8 דקות, או חצי שעה מאז הריצה האחרונה). ריצה שלא אוספת נגמרת בכמה שניות ולא מבצעת commit.

| קובץ | תוכן |
|---|---|
| `data/presentations.csv` | שורה לכל הקרנה: כל השדות שה-API מחזיר (סרט, אולם, שפה, משך, תחילת מכירה ועוד), ובנוסף מתי נראתה לראשונה ולאחרונה ומה הייתה הזמינות אז |
| `data/changes/YYYY-MM.csv` | שורה רק כשזמינות הכרטיסים משתנה: עקומת המכירות של כל הקרנה |
| `data/runs/YYYY-MM.csv` | שורה לכל ריצה: מאפשר לבדוק כיסוי ופערים |
| `data/attendance.csv` | אומדן כרטיסים לכל הקרנה שהתחילה (עמודת `excluded` מסמנת אירוע קצה) |
| `data/exclusions.csv` | אירועי קצה (חגים, ימי קולנוע מוזלים): הקרנות בתאריכים האלה לא נכנסות לממוצעים |
| `data/summary.json` | סיכומים: לפי יום, חלון שעה, שבוע וסרט, והקרנות קרובות |
| `data/snapshots-flat.csv` | אותם נתונים בפורמט הישן של הכלים המקומיים |
| `data/legacy/` | צילומים שנאספו במחשב לפני שהמעקב עבר ל-GitHub |

## שיטת האומדן
כרטיסים = `round((1 - availRatio) × 267) − 2`. אולם לב סמדר מונה 267 מושבים (אומת מול מפת המושבים),
ומתוכם 2 מושבים חסומים שה-API מציג כתפוסים, ולכן הם מנוכים מכל הקרנה (הספירה הגולמית יצאה גבוהה ב-2 באופן עקבי). האומדן "סופי" כשההקרנה נראתה לאחרונה עד 20 דקות לפני תחילתה.
מכירות בקופה ברגע האחרון עלולות לא להיכלל.

הקרנות שחלות באירועי קצה (חול המועד, יום הקולנוע וכדומה, לפי `data/exclusions.csv`) נשמרות בנתונים ומסומנות, אבל לא נכנסות לאף ממוצע (לפי יום, שעה, שבוע או סרט). הן מוצגות בנפרד בטבלת "אירועי קצה".
